# Hospital Patient Management System

## Project Overview
The Hospital Patient Management System is a web-based application designed to manage patient records and organize hospital waiting queues. It demonstrates the practical application of data structures in healthcare management.

## Objectives
- Maintain patient records efficiently.
- Manage regular patients using the FIFO principle.
- Prioritize emergency patients based on priority.
- Allow users to register, search, update, and remove patient records.
- Demonstrate the use of data structures in a real-world application.

## Features
- Patient registration
- Patient record search and management
- Regular patient queue management
- Emergency patient priority management
- Display and serve waiting patients
- Simple, responsive user interface

## Technologies Used
- HTML
- CSS
- JavaScript
- Java

## Data Structures Used
- **Queue:** Manages regular patients using First-In-First-Out (FIFO).
- **Priority Queue:** Gives higher-priority emergency patients precedence.
- **Linked List:** Supports dynamic patient record management.

## How to Run
1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Use the interface to register and manage patients.

## Limitations
- Web application data is stored temporarily and may be lost after refreshing the page.
- The current prototype does not use a permanent database.
- It is intended for educational purposes.

## Future Enhancements
- Integrate a database for permanent storage.
- Add secure login for hospital staff.
- Generate patient reports.
- Improve emergency management features.

## Conclusion
The project demonstrates how queues, priority queues, and linked lists can be applied to patient record management and hospital queue organization.
